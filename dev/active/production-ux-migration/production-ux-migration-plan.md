# Production UX migration plan

- Created: 2026-09-25
- Last Updated: 2026-09-25
- Status: In Progress

## Objective

Bring the strongest interaction and visual ideas from the Lovable prototype into the production Next.js application without replacing production contracts, authentication, compliance, URLs, or backend behavior.

## Scope

1. Establish enforceable UX capability, design, responsive, accessibility, and quality gates.
2. Package the production theme as a project-specific Codex skill.
3. Treat Patient Guidance as a documented future concept only.
4. Migrate one complete journey at a time, beginning with discovery, comparison, and product evaluation.
5. Preserve existing production functionality while replacing inconsistent presentation incrementally.

## Sequence

1. Documentation and reusable design guidance.
2. Shared public shell and responsive primitives.
3. Search and filtering.
4. Product evaluation and dispensary handoff.
5. Dispensary directory, detail, and inventory.
6. Watchlist, authentication transitions, profile, and notification settings.
7. Convergence, accessibility, and route-compatibility review.

## Out of scope

- A Patient Guidance page.
- Guest review submission.
- SMS notifications.
- Unsupported recommendation, deal-feed, personalization, or purchasing capabilities.
- Copying Lovable's Vite routing, fixtures, local authentication, or component library into production.
